# 🐾 Animal Management System

A full-stack application for managing animal records, built with **Angular** and **Node.js**.

## 📌 About the Project

This project is a personal coding exercise designed to keep my software development skills sharp while I continue specializing in **AI Agents**.

The goal is to maintain consistency in coding practices, reinforce software architecture fundamentals, and continue improving my skills in frontend and backend development.

The application provides an animal management system with CRUD (Create, Read, Update, Delete) operations, allowing users to register, view, update, and delete animal records.

## 🚀 Technologies

- **Angular** — Frontend development
- **Node.js** — Backend development
- **REST API** — Communication between frontend and backend
- **CRUD Operations** — Animal record management

## ✨ Features

- Register new animals
- List registered animals
- View animal information
- Update animal records
- Delete animal records
